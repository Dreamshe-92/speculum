# Speculum

> 无涯

一面照不到边的镜子。

十三世纪，博韦的樊尚编了一部 *Speculum Maius*——《大镜》。他想把当时所有的知识收进同一部书：自然、学问、历史。后来有人又替他补上第四卷「道德」，那时他已去世多年。全书始终没有真正定稿，却一直被传抄、增补、重排了几个世纪。

这个仓库借它的名字，也借它的未完成。

《庄子·养生主》说：「吾生也有涯，而知也无涯。以有涯随无涯，殆已。」庄子的本意是劝人别拿有限的生命去硬追无限的知识。这里偏偏反着用一次：明知收不完，还是开了一间。不承诺完整，不设边界，也不欠自己一笔「待整理」的债。

**不做万物，只留位置。收得下多少算多少，反正本来也收不完。**

## 此刻：只点了一盏灯

名字起得大，事情可以做得小。这个仓库目前只做一件事：**把 AI 生成的东西，调到顺眼为止。**

可能是一张图、一段排版、一组配色、一句提示词的第三次改写。没有终版，只有这一版比上一版耐看一点——「无涯」落在审美上，说的正是这个。

其余位置先空着。空着不是欠债，是留白；哪天想放别的，镜子还照得下。

在线看：`https://<user>.github.io/speculum/`（GitHub Pages，配置见文末）

## 四镜一格

前四卷沿用《大镜》的分法，按「东西是什么／人怎么懂它／它经历过什么／该怎么权衡」分开；第五格专门放那些还不该被归类的。下表的「此刻」写的是现在用在审美优化上的样子，不是上限。

| 目录 | 卷 | 此刻放什么 |
| --- | --- | --- |
| `naturale/` | 自然之镜 · *Speculum Naturale* | 原图、未经改动的输入、找来的参照 |
| `doctrinale/` | 学问之镜 · *Speculum Doctrinale* | 提示词、参数、风格笔记、可复用的调法 |
| `historiale/` | 历史之镜 · *Speculum Historiale* | 前后两版对照、改了什么、哪版留下 |
| `morale/` | 权衡之镜 · *Speculum Morale* | 「顺眼」到底指什么：判断标准、取舍、复盘 |
| `incerta/` | 未定 · *Incerta* | 还看不出好坏的，先搁着 |

四卷不必齐备，顺序也不代表高下。第四卷本就是后人所补，第五格索性一直空着——它们存在的意思，是这面镜子允许被继续加页。

一条只给自己定的规矩：**放进来比放对地方优先**。分类可以慢慢长，先别让东西停在收件箱里。

## 风格案例：先按清单照见

从一份 100 个网站案例的清单里，照见能打开、且免费或主要免费可看的 81 例；原文明确付费／部分付费的 11 例、两条实际内容通道都未取得站点自身页面证据的 8 例，暂且留在跳过表里。

- `doctrinale/style-cases/`：每例一页风格 md。名称、分类、URL、描述与「风格要点」都照清单原文；抓到的页面元数据只作访问核验线索，不写成原站风格结论。
- `styles/`：同一批事实的 HTML 画廊与每例独立展示页，按九类版式陈列，并带真实可用的搜索与分类筛选。
- `doctrinale/prompts/`：每例一页 AI 提示词模板。原文按句读机械切成片段，逐字保留；骨架只规定怎么使用素材，不替原站下风格结论。案例页可填任务与约束、实时预览、一键复制。
- 首页可从 `styles/` 进去；本地 `npm run dev` 也能看。判据与跳过表都写在 `doctrinale/style-cases/README.md` 和 `styles/README.md`，提示词用法写在 `doctrinale/prompts/README.md`。

规矩还是那一条：**不自作主张，先留位置**。哪天清单变了，镜子再照一遍。

## 站点：开一盏免费的灯

这个仓库同时是站点的源码，根目录的 `index.html` 就是首页。不买域名、不租服务器：

1. 仓库保持 **public**（GitHub Free 下 Pages 要求公开仓库）。
2. `Settings → Pages → Build and deployment`：Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。
3. 稍等片刻，打开 `https://<user>.github.io/speculum/`。以后每次 push 到 `main` 自动更新。

几点记在这里，省得以后重新查：

- 想让地址更短，把仓库命名为 `<user>.github.io`，地址就变成 `https://<user>.github.io/`；代价是一个账号只能有这一个这样的站点，仓库名也不再叫 `speculum`。
- 根目录那个空的 `.nojekyll` 是让 Pages 别用 Jekyll 再加工一遍，`index.html` 原样发布；以后接任何静态生成器都不用先拆它。
- 站点是公开的，即使仓库设成私有也一样。密钥、未公开素材别放进来。
- 首页的卷名链接会在 `*.github.io` 下自动指回仓库对应目录，本地打开时只作展示、不产生死链。仓库改名时项目站点的 URL 不会自动跟着重定向，所以名字最好一次定下，或早点绑自定义域名。
- 本地想先看一眼：`npm run dev`，然后开 `http://localhost:7100/`。零依赖，用的只是 Node 自带的静态服务。

规则以 [GitHub Docs](https://docs.github.com/en/pages) 为准。

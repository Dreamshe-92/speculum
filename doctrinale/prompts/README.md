# AI 提示词模板 · 原文关键词

> 无涯 · 学问之镜 / 可喂给 AI 的那一版

为已保留的 **81** 例各写一页模板。目标不是替原站总结风格，而是把清单原文变成能直接粘贴给 AI 的素材。

## 三条规矩

1. **关键词不改写**：按原文句读机械切分所得片段，保留原字，去重、保序；不归纳、不翻译、不补同义词。
2. **骨架只是使用规则**：角色、任务、约束、输出要求是通用结构，不含任何「该站风格是 X」的判断。
3. **方括号由你填**：`【我的任务】` 与 `【我的约束】` 是占位符；页面里可边填边预览并一键复制。

## 模板结构

| 段 | 内容 | 谁写的 |
| --- | --- | --- |
| 参照案例 / 原站 / 清单分类 | 编号、名称、URL、分类 | 清单原文 |
| 参照素材 · 原文关键词片段 | 机械切分的原文片段 | 清单原文，未改字 |
| 参照素材 · 原文全文 | 完整描述 | 清单原文 |
| 我的任务 / 我的约束 | 方括号占位 | 使用者 |
| 输出要求 | 逐字引用、未知标「待定」、不编造站点细节 | 通用使用规则 |

第 2、4 条输出要求是关键：它防止 AI 把「没写」脑补成「有风格」。

## 怎么用

- **最快**：打开任意一例的 HTML 展示页，填两格，点「复制提示词」，粘贴给 AI。
- **写文档 / 存档**：复制本目录对应 md 里「可复制提示词」的一整段。
- **只要一行**：用「速用版」，它只取前 6 个原文片段。
- **换任务不换素材**：同一个案例的关键词可以反复用，只需改 `【我的任务】`。

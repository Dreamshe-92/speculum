# 网站案例风格库

> 无涯 · 学问之镜 / 风格笔记

按清单原文照见 100 个编号网站：保留可打开且免费可看的 **81** 例，跳过 **19** 例。每例一页 md，并在 [`../../styles/`](../../styles/) 有一页独立 HTML 展示；[`../prompts/`](../prompts/README.md) 另有把原文转成 AI 提示词素材的 81 页模板。

## 判据

- 名称、分类、URL、描述与「风格要点」均照清单原文，不凭印象补写。
- 「非免费」：原文明确付费、部分付费或订阅才能完整使用。
- 「打不开」：本机 curl 与网页内容通道均未取得站点自身页面证据。本机被拦但能读到站点自身页面者不跳过。
- 「实测访问线索」与「实测页面线索」只记录核验事实；页面字体／颜色等仅作辅助，不改写为原文没有的风格判断。

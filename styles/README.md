# 网站案例风格库 · HTML 展示

按清单原文照见 100 个编号网站：保留 **81** 例，跳过 **19** 例。

## 文件

- `index.html`：总画廊，含真实可用的搜索与分类筛选。
- `gallery.css`：九类展示格式与移动端、键盘焦点、减弱动效规则。
- `gallery.js`：仅过滤已渲染卡片，无死按钮。
- `data.js`：内嵌 `window.SPECULUM_CASES`，避免本地或 Pages 下 `fetch` JSON 失效。
- `prompt.js`：案例页把原文模板与使用者填写的任务拼成可复制提示词；复制不可用时退回选中预览文本。
- `cases/NNN-slug.html`：每个保留案例一个独立展示页，含提示词模板与「提示词 md」入口。
- `../hot/`：热门案例菜单页，12 个工坊示例的提示词与对应生成内容展示；素材来自附件 HTML 工坊，判据与本库 81 例清单不同，互不替代。
- `doctrinale/prompts/`：81 页提示词模板与用法索引；关键词逐字取自原文，不归纳改写。

## 展示格式

九个分类各用一种版式：奖项编辑式、动态帧序、3D 等距网格、电影信箱、UI Bento、网页杂志、前端终端、字体色票、日常瀑布。它们是本站的展示格式，不是对原网站风格的主观断言。

## 收录判据

1. 案例名、分类、URL、描述与「风格要点」忠于清单原文。
2. 原文明确付费／部分付费／订阅才能完整使用，按「非免费」跳过。
3. 本机 curl 与网页内容通道均未取得站点自身页面证据，按「打不开」跳过；本机被拦但另有站点自身页面证据者保留。
4. 页面元数据只作为「实测页面线索（仅作辅助）」，不写成原文没有的风格结论。
5. 提示词模板的关键词按原文句读机械切分、逐字保留；提示词骨架只是使用规则，不新增风格判断。
